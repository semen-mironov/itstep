Звертайте увагу на зірочки

Створити меню навігації cтруктури проекту в провіднику. 
Під час наведення на пункт * (папку) випадає підсписок (другий рівень).

Вимоги:
- 2 рівня підсписків
- адресація на інщі сторінки ( у прикладі style, about, картинки) у новій вкладці
- на відповідній сторінці - контент що підходить по логіці (style - стилі основної задачі **, картинки - сторінки з відповідними картинками ***, about - коротка стилізована інформація про проект)
- кастомні іконки додані картинками ****
- стилізація схожа з прикладом у відео

Підказки:
- приблизна структура вашого проекту на скріншоті(картинки та другорядні html лежать в окремих папках - images та pages відповідно), структура проекту в провіднику ( завдання ) на відео
- * - вкладеним спискам задайте меншу ширину ніж загальному для зручності наведення, display: none - для скривання підменю, display: block - для повернення
- ** - для написання коду як тексту використовуйте <pre><code></code></pre> за необхідністю &lt або &gt для заміни < та >
- *** - html-сторінка із тегом img (задати ширину для гарного вигляду - картинки квадратні)
- **** - .folder::before { 
			   background: url('шлях до картинки') no-repeat center/contain; 
			   /*інші стилі*/;
			 }
